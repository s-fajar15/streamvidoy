## ✨ Overview

**Stream Downloader** adalah aplikasi web modern untuk menganalisis dan mengunduh video melalui antarmuka yang cepat, sederhana, dan responsif.
Project ini sebelumnya dikenal sebagai **Vidoy Downloader** dengan domain **vdy.to**.
Sekarang project telah di-rebrand menjadi:

**Stream Downloader**  
https://streamvidoy.up.railway.app/

Dibangun dengan **Next.js App Router**, **React 19**, dan **Tailwind CSS v4**, dengan dukungan untuk **Direct MP4** dan **HLS / M3U8**.

---

## 🚀 Features

- 🎥 Video URL Analysis
- 📦 Metadata Extraction
- ⚡ Direct MP4 Download
- 📺 HLS / M3U8 Support
- 📈 Real-time Download Progress
- 📂 Download History
- 🖼️ Thumbnail Extraction
- ⚙️ FFmpeg Media Processing
- 🌙 Dark Mode

## ⚙️ Installation

### 1. Clone Repository

    git clone https://github.com/s-fajar15/streamvidoy.git
    cd streamvidoy

### 2. Install Dependencies

    npm install

### 3. Install FFmpeg

#### Debian / Ubuntu

    sudo apt update
    sudo apt install ffmpeg -y

#### Termux

    pkg update
    pkg install ffmpeg

Check installation:

    ffmpeg -version
    ffprobe -version

### 4. Start Development Server

    npm run dev

Open:

    http://localhost:3000

---

## 📦 Production

Build the application:

    npm run build

Start the production server:

    npm start
